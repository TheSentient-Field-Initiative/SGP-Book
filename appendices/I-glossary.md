# Appendix I — Mathematical and Scientific Glossary

Plain-language definitions for the general reader. (Foundational SGP vocabulary: Appendix A.)

- **Relation.** A list of connections between dots: which pairs (x, y) are linked, including self-links (x, x).
- **Ordered pair / orientation.** (x, y) ≠ (y, x): arrows have direction. Reciprocity and asymmetry are extra, optional properties.
- **Isomorphism.** A renaming of dots preserving all connections; isomorphic structures are "the same up to labels."
- **Invariant subset.** A collection no arrow leaves: R(A) ⊆ A.
- **Closure system.** A family of subsets containing S and closed under intersection — the shape of "consequence structures."
- **Closure operator.** The rule sending each set to the smallest closed set containing it (everything it implies).
- **Fiber.** All relations sharing one consequence-structure: F_C = {R : Inv(R) = C}.
- **Canonical / maximal representative (R_C).** The largest wiring with given consequences; unique top of the fiber.
- **Essential vs. conditionally removable edge.** Must-stay vs. may-go wires of R_C.
- **Partial order.** A ranking with possible incomparabilities (prerequisites).
- **Lower set.** Downward-closed collection (with prerequisites included).
- **Covering pair.** A direct prerequisite link with nothing between.
- **Transitive reduction (T).** The skeleton of covering pairs.
- **Alexandrov topology.** Consequence-structures closed under arbitrary intersection (finite case: no restriction).
- **T0.** The structure tells every pair of dots apart (no duplicates).
- **Composition.** Chaining relations end to end (R followed by S).
- **Quantum state.** The vector encoding a system's measurable tendencies.
- **Entanglement.** Joint state that doesn't factor into parts; Bell violations; no-signaling respected.
- **Partial trace / reduced state.** The shadow of the whole visible from one part.
- **Boson / fermion.** Shareable-state vs. exclusive-state particle classes (Pauli exclusion for fermions).
- **Condensation (BEC).** Macroscopic occupation of one quantum state; order parameter φ(x).
- **Identical particles.** Same-species indistinguishability via symmetrized states; occupation numbers; Fock space. Cross-species identity is NOT implied.
