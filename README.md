# The Sentience Question

**What We Discovered, What We Could Not Derive, and the Search for Why This World Exists**

A book-length account of the Sentience-Generativity Program (SGP): its founding reversal (start from sentience, not matter), its ladder of mathematical investigations (response → relations → closure → fibers → boundaries), the famous physics it touched (entanglement, condensation, identical particles), its documented negative results, and the final portfolio decision — philosophical framework retained, explanatory claims suspended.
